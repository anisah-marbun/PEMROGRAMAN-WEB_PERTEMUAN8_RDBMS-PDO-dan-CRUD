## Deskripsi

Project ini merupakan aplikasi sederhana untuk mengelola data inventaris barang menggunakan PHP dan MySQL.

Aplikasi memiliki fitur CRUD (Create, Read, Update, Delete) untuk data produk serta menggunakan kategori dan supplier sebagai data yang berelasi dengan produk.

## Teknologi yang Digunakan

- MySQL
- XAMPP
- phpMyAdmin
